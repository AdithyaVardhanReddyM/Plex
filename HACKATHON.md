# PayPal AI Hackathon — Notes

Source: https://paypalaihackathon.devpost.com (read 2026-11-05)

## Key facts
- **Deadline:** 13 Nov 2026 @ 1:30am IST (12 Nov, 12:00pm PT)
- **Theme:** No tracks. The only hard rule: the project must *meaningfully* use both PayPal and AI.
- **Environment:** PayPal **sandbox** (free).
- Optional sponsor tools: AG Grid, APIMatic, Astropods, Bryntum, Channel3, Elastic, KERNEL, Postman, Render, Zapier.

## Submission checklist
- [ ] Working prototype (mockups and static demos are not accepted)
- [ ] Text description of features and functionality
- [ ] Functional demo: hosted URL **or** complete setup and run instructions in the repo
- [ ] List of AI tools and models used, and how each is used
- [ ] Public GitHub repo with all source code, assets and instructions, plus an open-source LICENSE file visible in the repo's About section
- [ ] Demo video under 3 min on YouTube (public), showing the project running on its target device, with no unlicensed music or trademarks

## Judging criteria
1. **Technological implementation:** depth and skill of the PayPal + AI usage; must be non-trivial
2. **Design:** a complete, coherent product, not just a proof of concept
3. **Potential impact:** a real problem for a real audience, solved as shown in the demo
4. **Innovation:** novelty compared with existing concepts
5. **Presentation:** the video shows the project working end-to-end, with a clear problem, audience and reason it matters

## Prizes worth targeting
- 1st/2nd/3rd: $12k / $8k / $5k
- $5k each: Most Creative, Most Impactful, Best Demo Delivery, **Best Use of PayPal + AI**, **Best Use of Agentic Commerce**
- Sponsor prizes: AG Grid (up to $5k), APIMatic, Bryntum, Channel3, Render credits
